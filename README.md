# 📊 Painel Eleitoral PE 2026 | Análise por Município

Aplicação interativa desenvolvida para visualização e análise de dados da apuração dos votos da eleição presidencial de 2026 no estado de Pernambuco. O dashboard permite explorar os resultados detalhados nos 185 municípios pernambucanos tanto para o 1º como para o 2º turno.

🔗 **Aceda ao projeto online:** [Clique aqui para visualizar o Painel no GitHub Pages](https://feliperios-data.github.io/dashboard-eleicoes-pe-2026/)

---

## 📌 Funcionalidades Principais

- **Filtros Dinâmicos:** Alternância entre o **1º Turno** e o **2º Turno**, com seleção individual de qualquer um dos **185 municípios** de Pernambuco ou visualização consolidada do estado[cite: 1].
- **Métricas Chave (KPIs):**
  - Total de votos contabilizados[cite: 1].
  - Quantidade e percentual de votos válidos[cite: 1].
  - Líder municipal com percentual de validação[cite: 1].
  - Votos brancos e nulos com respectiva proporção[cite: 1].
- **Termómetro de Disputa:** Comparativo direto entre os dois principais candidatos em disputa no local selecionado[cite: 1].
- **Visualização Analítica:**
  - Gráfico horizontal de barras com o ranking dos candidatos mais votados[cite: 1].
  - Lista detalhada de todos os votáveis com número de campanha, partido, quantidade absoluta de votos e percentuais[cite: 1].

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3**
- **[Tailwind CSS](https://tailwindcss.com/):** Estilização moderna com design responsivo em modo escuro (*Dark Mode*) e efeito *glassmorphism*[cite: 1].
- **[Chart.js](https://www.chartjs.org/):** Renderização de gráficos analíticos dinâmicos e reativos[cite: 1].
- **JavaScript (Vanilla):** Tratamento das estruturas de dados, cálculos em tempo real e atualização de componentes da interface sem recarregamento de página[cite: 1].
